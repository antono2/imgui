V + Dear ImGui GLFW/Vulkan Demo - Windows 10/11 x64
===================================================

Extract the complete archive and run:

    v_imgui_demo.exe

The package contains the compiled V example, vimgui.dll, glfw3.dll, and
VARIANT.txt. The selected variant is also displayed inside the demo.

A Vulkan-capable display driver is required. The Vulkan loader and GPU driver
come from Windows or the installed graphics driver and are not bundled.

Install the Microsoft Visual C++ 2015-2022 Redistributable (x64) before running
the demo. Keep both DLL files beside it when moving or copying the package.
